    Internal Modules & API Reference

    Task Manager is built with pure HTML, CSS, and modular Vanilla JavaScript ES modules so each feature can be maintained cleanly:

    index.html

    Semantic HTML5 layout for the header, metrics strip, 5-mode filter bar, task list, Recycle Bin, modals, and AI Helper chatbox.

    src/styles/main.css

    Responsive CSS stylesheet using custom properties, Grid, Flexbox, and accessible focus/reduced-motion rules.

    src/js/storage.js

    Browser persistence (localStorage) with validation and optional Supabase sync.

    src/js/taskHelpers.js

    Pure domain functions for duplicate detection, urgency/completion sorting, 5-mode filtering, metrics, and date formatting.

    src/js/renderers.js & src/js/main.js

    Safe DOM rendering (no raw HTML injection) and application state/event controller.

    POST /api/ai-helper (server.ts)

    Express endpoint calling Gemini on the server for on-demand productivity inquiries.

    Local-First Task Storage

    All tasks, descriptions, classifications, due dates, and Recycle Bin items are stored inside your browser's localStorage under key taskledger_workspace_v1.

    • Zero task transmission to AI: Your saved task list is never sent to external AI services or public endpoints.
    • Isolated AI Helper: Only the question you explicitly type inside the AI Helper Chatbox is sent to /api/ai-helper.
    • Safe deletion lifecycle: Individual task deletions and completed-task clears confirm first and move items to the Recycle Bin before permanent deletion.
